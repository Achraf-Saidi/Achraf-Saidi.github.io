Backpropagation: differentiating a small network end to end

65 min · Reading & practice

What should change when a network is wrong?

Section titled “What should change when a network is wrong?”

A prediction depends on successive calculations. To correct parameters, we need each parameter’s effect on the final error. Backpropagation efficiently applies the chain rule to this computational graph. It calculates derivatives; gradient descent then uses them to update parameters. These are distinct operations.

Prerequisite: regression and gradients, including differentiation and composition. Goals: execute a forward pass, calculate all four gradients of a small network and check a gradient numerically. This is a one-hidden-unit regression network, not a biological system or a large model.

A tiny network with every quantity defined

Section titled “A tiny network with every quantity defined”

The scalar input is xxx and the target is yyy. Layer one has weight w1w_1w1​ and bias b1b_1b1​, producing z=w1x+b1z=w_1x+b_1z=w1​x+b1​ followed by h=tanh⁡(z)h=\tanh(z)h=tanh(z). Layer two has w2,b2w_2,b_2w2​,b2​ and produces y^=w2h+b2\hat y=w_2h+b_2y^​=w2​h+b2​. The one-observation loss is L=(y^−y)2/2L=(\hat y-y)^2/2L=(y^​−y)2/2.

The activation tanh⁡(z)=(ez−e−z)/(ez+e−z)\tanh(z)=(e^z-e^{-z})/(e^z+e^{-z})tanh(z)=(ez−e−z)/(ez+e−z) is smooth and lies between −1-1−1 and 1; eze^zez denotes the exponential. Its derivative is 1−tanh⁡2(z)1-\tanh^2(z)1−tanh2(z). Calling numerator NNN and denominator DDD, we have N′=DN'=DN′=D and D′=ND'=ND′=N, hence (N/D)′=(D2−N2)/D2=1−(N/D)2(N/D)'=(D^2-N^2)/D^2=1-(N/D)^2(N/D)′=(D2−N2)/D2=1−(N/D)2. Nonlinearity prevents the entire composition from collapsing into a single affine transformation.

z=0.5,h=tanh⁡(0.5)≈0.462117,z=0.5,\qquad h=\tanh(0.5)\approx0.462117,z=0.5,h=tanh(0.5)≈0.462117, y^=2h≈0.924234,L≈0.00287022.\hat y=2h\approx0.924234,\qquad L\approx0.00287022.y^​=2h≈0.924234,L≈0.00287022.

Store useful intermediate values, especially hhh. Recomputing the entire network separately for each parameter would waste work.

Moving backwards from loss to parameters

Section titled “Moving backwards from loss to parameters”

Let δ=∂L/∂y^=y^−y≈−0.075766\delta=\partial L/\partial\hat y=\hat y-y\approx-0.075766δ=∂L/∂y^​=y^​−y≈−0.075766. This signal measures the local effect of the output on loss. For the last layer:

∂L∂w2=δh,∂L∂b2=δ.\frac{\partial L}{\partial w_2}=\delta h,\qquad\frac{\partial L}{\partial b_2}=\delta.∂w2​∂L​=δh,∂b2​∂L​=δ.

The signal reaching hhh is ∂L/∂h=δw2\partial L/\partial h=\delta w_2∂L/∂h=δw2​. Passing through the activation gives ∂L/∂z=δw2(1−h2)\partial L/\partial z=\delta w_2(1-h^2)∂L/∂z=δw2​(1−h2). Finally:

∂L∂w1=δw2(1−h2)x,∂L∂b1=δw2(1−h2).\frac{\partial L}{\partial w_1}=\delta w_2(1-h^2)x,\qquad\frac{\partial L}{\partial b_1}=\delta w_2(1-h^2).∂w1​∂L​=δw2​(1−h2)x,∂b1​∂L​=δw2​(1−h2).

Each factor follows an edge of the composition: loss to output, output to hhh, hhh to zzz, and zzz to the parameter. For these values, gradients with respect to w2,b2,w1,b1w_2,b_2,w_1,b_1w2​,b2​,w1​,b1​ are approximately −0.03501-0.03501−0.03501, −0.07577-0.07577−0.07577, −0.11917-0.11917−0.11917, −0.11917-0.11917−0.11917. Their negative signs mean that a small increase in these parameters decreases loss locally. A large increase might do the opposite.

Code and an independent check

Section titled “Code and an independent check”

The central finite difference actually perturbs a parameter and measures the loss change. It does not reuse the analytic gradient formula, making it an independent check. Too large a displacement distorts the approximation; too small amplifies rounding errors. This check does not prove correctness on every input, but catches many sign and factor mistakes.

From scalars to matrices

Section titled “From scalars to matrices”

For a layer with ddd inputs and mmm outputs, z=Wx+bz=Wx+bz=Wx+b, with x∈Rdx\in\mathbb R^dx∈Rd, W∈Rm×dW\in\mathbb R^{m\times d}W∈Rm×d and b,z∈Rmb,z\in\mathbb R^mb,z∈Rm. If the incoming signal is g=∂L/∂z∈Rmg=\partial L/\partial z\in\mathbb R^mg=∂L/∂z∈Rm, then ∂L/∂W=gxT\partial L/\partial W=gx^T∂L/∂W=gxT and ∂L/∂x=WTg\partial L/\partial x=W^Tg∂L/∂x=WTg. The first product has size m×dm\times dm×d; the second has dimension ddd. Dimensions check the formulas. For several observations, sum or average contributions according to the chosen loss.

In PyTorch, tensors marked requires_grad=True record the graph. Calling loss.backward() calculates and accumulates gradients; reset them between independent updates. Automatic differentiation saves manual rules but does not choose the right loss, data or evaluation protocol.

Exercises

Section titled “Exercises”
  1. Why does the loss factor 1/21/21/2 disappear from δ\deltaδ?
  2. If x=0x=0x=0, what is the gradient with respect to w1w_1w1​? What about b1b_1b1​?
  3. Without an activation, why do two affine layers remain one affine function?
  4. What goes wrong if you update w2w_2w2​ before calculating the gradient for w1w_1w1​?
Worked solutions
  1. Differentiating (y^−y)2(\hat y-y)^2(y^​−y)2 gives a factor 2, cancelling 1/21/21/2.
  2. The gradient for w1w_1w1​ is zero because of the factor xxx. The bias gradient can remain nonzero: changing the bias changes zzz even when input is zero.
  3. W2(W1x+b1)+b2=(W2W1)x+(W2b1+b2)W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)W2​(W1​x+b1​)+b2​=(W2​W1​)x+(W2​b1​+b2​) is still affine.
  4. The gradients no longer correspond to the same parameter point. Calculate all gradients for the current forward pass before updating parameters.
