Vectors and matrices: calculations with geometry

60 min · Reading & practice

A data point can be a vector

Section titled “A data point can be a vector”

Describing an observation by height and mass requires two ordered numbers. A vector x=(x1,x2)x=(x_1,x_2)x=(x1​,x2​) is an element of R2\mathbb R^2R2, with coordinates x1,x2x_1,x_2x1​,x2​. Geometrically, draw it as a displacement from the origin. In data science, interpret it as a list of measurements. This dual view connects calculation and representation.

Prerequisite: algebra. Goals: compute linear combinations and dot products, read matrix dimensions, explain matrix–vector multiplication and compose transformations.

Adding and measuring

Section titled “Adding and measuring”

Addition acts coordinate by coordinate: (1,2)+(3,−1)=(4,1)(1,2)+(3,-1)=(4,1)(1,2)+(3,−1)=(4,1). Multiplication by a real scalar α\alphaα gives α(1,2)=(α,2α)\alpha(1,2)=(\alpha,2\alpha)α(1,2)=(α,2α). A linear combination of vectors u,vu,vu,v has the form au+bvau+bvau+bv with real coefficients a,ba,ba,b. The vectors e1=(1,0)e_1=(1,0)e1​=(1,0) and e2=(0,1)e_2=(0,1)e2​=(0,1) express any x=(x1,x2)x=(x_1,x_2)x=(x1​,x2​) as x1e1+x2e2x_1e_1+x_2e_2x1​e1​+x2​e2​.

The dot product uTv=∑j=1dujvju^Tv=\sum_{j=1}^d u_jv_juTv=∑j=1d​uj​vj​ produces a number from two vectors with ddd coordinates; ∑\sum∑ means summing terms indexed by jjj from 1 to ddd. The superscript TTT denotes transpose, turning a column into a row. For u=(1,2)u=(1,2)u=(1,2) and v=(3,−1)v=(3,-1)v=(3,−1), uTv=3−2=1u^Tv=3-2=1uTv=3−2=1.

The Euclidean norm is ∥u∥=uTu\|u\|=\sqrt{u^Tu}∥u∥=uTu​. For (3,4)(3,4)(3,4) it equals 5, as in Pythagoras’ theorem. Nonzero vectors are orthogonal when their dot product is zero. With measurements in different units, this numerical geometry depends on scaling: converting centimetres to metres changes distances unless scaling is handled.

A matrix specifies what happens to the axes

Section titled “A matrix specifies what happens to the axes”

A matrix A∈Rm×dA\in\mathbb R^{m\times d}A∈Rm×d has mmm rows and ddd columns. It maps a vector with ddd coordinates to one with mmm coordinates. Take

A=(1201),x=(34).A=\begin{pmatrix}1&2\\0&1\end{pmatrix},\qquad x=\begin{pmatrix}3\\4\end{pmatrix}.A=(10​21​),x=(34​).

An equally useful interpretation: AxAxAx is a combination of the columns of AAA, weighted by coordinates of xxx: 3(1,0)+4(2,1)=(11,4)3(1,0)+4(2,1)=(11,4)3(1,0)+4(2,1)=(11,4). Multiplication means composition

Section titled “Multiplication means composition”

If AAA maps dimension ddd to mmm, and BBB maps dimension mmm to kkk, then BABABA has size k×dk\times dk×d and BAx=B(Ax)BAx=B(Ax)BAx=B(Ax). The inner dimensions must agree. Its row-iii, column-jjj entry is (BA)ij=∑r=1mBirArj(BA)_{ij}=\sum_{r=1}^m B_{ir}A_{rj}(BA)ij​=∑r=1m​Bir​Arj​.

Order matters. For A=(1101)A=\begin{pmatrix}1&1\\0&1\end{pmatrix}A=(10​11​) and B=(2001)B=\begin{pmatrix}2&0\\0&1\end{pmatrix}B=(20​01​), AB=(2101)AB=\begin{pmatrix}2&1\\0&1\end{pmatrix}AB=(20​11​) whereas BA=(2201)BA=\begin{pmatrix}2&2\\0&1\end{pmatrix}BA=(20​21​). A shear followed by a stretch need not match the reverse order.

Computing transparently

Section titled “Computing transparently”

With NumPy, np.array(A) @ np.array(x) performs this product. The * operator means elementwise multiplication, not matrix multiplication. In R, matrix multiplication uses %*%; * is also elementwise. Always inspect array shapes.

Exercises

Section titled “Exercises”
  1. Calculate the dot product of (1,−1)(1,-1)(1,−1) and (2,2)(2,2)(2,2) and interpret it.
  2. Can a 3×43\times43×4 matrix multiply a three-dimensional vector? What output size would a valid input produce?
  3. Find the image of (1,2)(1,2)(1,2) under (0−110)\begin{pmatrix}0&-1\\1&0\end{pmatrix}(01​−10​).
  4. Why is a square matrix with two identical columns noninvertible?
Worked solutions
  1. 1×2−1×2=01\times2-1\times2=01×2−1×2=0: the vectors are orthogonal.
  2. No: it expects 4 coordinates. Its output has 3 coordinates.
  3. The image is (−2,1)(-2,1)(−2,1), a counterclockwise quarter-turn.
  4. It maps (1,0)(1,0)(1,0) and (0,1)(0,1)(0,1) to the same vector in the two-dimensional case. Distinct inputs sharing an output prevent a unique inverse. In dimension 2, the determinant is zero; the same column-dependence argument extends to larger square matrices.
