Functions: connecting an input to an output

45 min · Reading & practice

Can a formula be a model?

Section titled “Can a formula be a model?”

A taxi charges €4 initially and €2 per kilometre. For distance xxx in kilometres, its price is f(x)=4+2xf(x)=4+2xf(x)=4+2x euros. The letter fff names the rule; f(x)f(x)f(x) is the output associated with input xxx. At 3 km, f(3)=10f(3)=10f(3)=10. This model assumes constant pricing, with no waiting or supplements. A formula applies within its assumptions.

Prerequisite: variables and equations. Goals: interpret functions, determine domains, construct graphs, compose rules and recognize affine functions.

A precise definition

Section titled “A precise definition”

A function f:D→Cf:D\to Cf:D→C assigns each element xxx of an input set DDD exactly one value f(x)f(x)f(x) in an output set CCC. The set DDD is the domain; CCC is the codomain. The set of outputs actually attained is the image f(D)f(D)f(D), which can be smaller than CCC.

For f:R→Rf:\mathbb R\to\mathbb Rf:R→R with f(x)=x2f(x)=x^2f(x)=x2, the domain is R\mathbb RR but the image is [0,∞)[0,\infty)[0,∞). Inputs 2 and −2-2−2 share output 4: an output can have several preimages. A function cannot assign two different outputs to the same input.

Operations restrict the domain: g(x)=1/(x−1)g(x)=1/(x-1)g(x)=1/(x−1) requires x≠1x\ne1x=1; the real-valued function s(x)=xs(x)=\sqrt{x}s(x)=x​ requires x≥0x\ge0x≥0. Context can restrict it further: for the taxi, x≥0x\ge0x≥0.

Plotting input–output pairs

Section titled “Plotting input–output pairs”

The graph of fff is the set of points (x,f(x))(x,f(x))(x,f(x)). For f(x)=x2f(x)=x^2f(x)=x2, some points are (−2,4),(−1,1),(0,0),(1,1),(2,4)(-2,4),(-1,1),(0,0),(1,1),(2,4)(−2,4),(−1,1),(0,0),(1,1),(2,4). The horizontal axis shows inputs; the vertical axis shows outputs. Joining a few points arbitrarily does not prove what happens between them; the formula and its properties provide that information.

An affine function has the form f(x)=ax+bf(x)=ax+bf(x)=ax+b, with fixed real numbers a,ba,ba,b. Its vertical intercept is b=f(0)b=f(0)b=f(0). For distinct inputs x1,x2x_1,x_2x1​,x2​:

f(x2)−f(x1)x2−x1=a(x2−x1)x2−x1=a.\frac{f(x_2)-f(x_1)}{x_2-x_1}=\frac{a(x_2-x_1)}{x_2-x_1}=a.x2​−x1​f(x2​)−f(x1​)​=x2​−x1​a(x2​−x1​)​=a.

This rate of change is constant, and aaa is its slope. A positive aaa makes the function increasing; a negative aaa makes it decreasing; zero makes it constant. An increasing graph need not have constant slope: x2x^2x2 increases on positive inputs while its slope changes.

Composing operations

Section titled “Composing operations”

Let f(x)=x+1f(x)=x+1f(x)=x+1 and g(u)=u2g(u)=u^2g(u)=u2, where uuu denotes the input of ggg. The composition g∘fg\circ fg∘f means “apply fff, then ggg”:

(g∘f)(x)=g(f(x))=(x+1)2.(g\circ f)(x)=g(f(x))=(x+1)^2.(g∘f)(x)=g(f(x))=(x+1)2.

In the other order, (f∘g)(x)=x2+1(f\circ g)(x)=x^2+1(f∘g)(x)=x2+1. At x=2x=2x=2, the outputs are 9 and 5: order matters. Neural networks are also compositions of transformations.

An inverse function reverses a bijective correspondence between the chosen domain and codomain. Squaring on R\mathbb RR is not invertible because 2 and −2-2−2 both give 4. Restricting both domain and codomain to [0,∞)[0,\infty)[0,∞) gives square root as its inverse. The notation f−1f^{-1}f−1 does not generally mean 1/f1/f1/f.

A first implementation

Section titled “A first implementation”

A Python function implements a procedure; a mathematical function is a correspondence. Here they represent the same rule on accepted numerical inputs. A procedure that changes a file or depends on random draws requires more care in this comparison.
