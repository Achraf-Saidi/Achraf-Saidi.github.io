Four complete experiments connect calculations to reproducible results. **Iris** and **Wine** use real measurements; **gradient** and **backpropagation** provide synthetic computational checks. None is a clinical or industrial system.

[Download the project bundle](/achraf-notebooks/downloads/projects.zip). Python 3.11+ is recommended. For Iris and Wine install `numpy==2.3.5` and `scikit-learn==1.8.0`, the versions used for the recorded results. Once installed, scikit-learn’s bundled data requires no account or additional external download. The gradient experiments use only the standard library.

## 1. A line that learns

**Level:** foundational, about 1 h. **Prerequisites:** [regression](/achraf-notebooks/en/learning/regression/) and Python. **Question:** can gradient descent recover a known line? The synthetic observations are $(0,1),(1,3),(2,5)$, created directly in code without an external data source.

**Tasks.** Implement MSE and its two derivatives. Calculate the first step by hand and compare it with the program. Take 300 steps with learning rate 0.1, then compare slope and intercept against the direct solution. Deliver parameters, final loss and an explanation of divergence with excessive learning rates.

The initial zero-line baseline has MSE $35/3$. The tested solution approaches $w=2,b=1$ within $10^{-6}$. This checks optimization algebra, not generalization: the construction is deterministic and exactly linear.

<summary>Progressive hints</summary>

1. Use the old parameters for both gradients. 2. Initial derivatives are −26/3 and −6. 3. Loss increasing across steps suggests reducing the learning rate.

</details>

## 2. Classifying Iris flowers

**Level:** applied beginner, 2–3 h. **Prerequisites:** Python, vectors, distances and training/test separation. **Goal:** compare a constant baseline with nearest-centroid classification while preventing preprocessing leakage.

**Data.** There are 150 flowers, four centimetre measurements—sepal and petal lengths and widths—and three species classes. Scikit-learn encodes labels from 0 to 2. We use `load_iris()`, whose documentation describes a corrected Fisher/R version differing at two observations from the historical UCI version. [Scikit-learn documentation and dictionary](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html), [UCI attribution and documentation](https://archive.ics.uci.edu/dataset/53/iris), [UCI archive](https://archive.ics.uci.edu/static/public/53/iris.zip). UCI states CC BY 4.0; cite R. A. Fisher, Iris, DOI 10.24432/C56C76. This project does not redistribute data.

**Protocol.** Reserve 30% with `random_state=42` and stratify to retain class proportions. Fit scaling on the **105 training observations** only: subtract each training variable’s mean and divide by its training standard deviation. Compute each class’s mean vector in scaled training space. Assign test observations to their nearest centroid by Euclidean distance. The `most_frequent` baseline always predicts the training majority class.

**Tasks and outputs.** Reproduce the computation on a small example, then with NumPy and a scikit-learn pipeline. Report accuracy and a confusion matrix with class ordering. On the 45 test observations, the recorded execution gives **0.822222**, versus **0.333333** for the baseline. The matrix is `[[15,0,0],[0,11,4],[0,4,11]]`. The solution independently verifies that manual and pipeline predictions agree.

An estimate based on 45 flowers is not universal accuracy; another sample would change it. If you introduce hyperparameters, select them using internal training validation while keeping test data separate. Watch for target labels accidentally included as features, globally fitted scaling and misaligned feature rows.

<details>
<summary>Progressive hints</summary>

1. Labels group the training rows. 2. Each centroid has four coordinates, not 105. 3. Test data reuses training means and standard deviations. 4. Confusion-matrix entries must sum to 45.

</details>

## 3. Summarizing Wine with two PCA axes

**Level:** intermediate, 3–4 h. **Prerequisites:** scaling, matrix products, orthogonality and variance; the complete PCA lesson is still planned. This brief and solution are a guided experiment rather than the full theory course.

**Data.** Wine contains 178 observations and 13 chemical measurements from three cultivars. The function `load_wine()` supplies values, feature names and labels; labels do not determine the PCA axes. [Scikit-learn documentation](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html), [UCI dictionary and attribution](https://archive.ics.uci.edu/dataset/109/wine), [UCI archive](https://archive.ics.uci.edu/static/public/109/wine.zip). Cite S. Aeberhard and M. Forina, DOI 10.24432/C5PC7J; UCI states CC BY 4.0. Chemical variables have different scales, so scaling choices must be explicit.

**Question.** How much numerical information is lost when projecting 13 variables onto two orthogonal axes? PCA finds directions of greatest variance in centred training data; they also minimize squared reconstruction error at a chosen rank. The complete derivation belongs in D14/F8.

**Protocol and tasks.** Split 70/30 with seed 42, giving 124 training observations and 54 test observations. Fit scaling and a two-component PCA using training data. Transform and reconstruct test data without refitting. Compare test MSE in standardized units against a constant reconstruction equal to the training mean. Verify that components are orthonormal and that reconstruction matches an explicit matrix product.

Recorded training explained-variance ratios are approximately **0.361962** and **0.187639**. Test reconstruction MSE is **0.400885**, compared with **0.929424** for constant reconstruction. Explained variance here concerns training data; it is not accuracy, causality or a guarantee that every biological or chemical structure is preserved.

<details>
<summary>Progressive hints</summary>

1. Each axis has 13 coefficients. 2. Projected outputs have two columns. 3. Reconstructions again have 13. 4. In the general reconstruction formula retain PCA’s fitted centring in addition to the scaler’s centring.

</details>

## 4. Checking backpropagation

**Level:** intermediate, 1–2 h. **Prerequisite:** [backpropagation lesson](/achraf-notebooks/en/learning/backpropagation/). **Question:** do manual derivatives agree with actual loss changes when each parameter is perturbed? The network and observation are synthetic.

Implement the forward pass, then gradients for both weights and biases. Independently calculate a central finite difference for each using displacement $10^{-6}$, keeping other parameters fixed. Recorded maximum absolute discrepancy is about **9.43 × 10⁻¹²**, below the $10^{-8}$ check threshold. This is a local numerical check, not a proof for every parameter value.

<details>
<summary>Hints and pitfalls</summary>

Recalculate loss for each perturbation. Do not reuse the analytic derivative to manufacture a “numerical reference”. Try several displacement magnitudes to observe truncation and rounding limitations.

</details>

## Reproduce and discuss

The bundle includes scripts, observed JSON outputs and dependency versions. From its `projects` directory run `python iris.py`, `python wine.py`, `python gradient.py` or `python backprop.py`. Assertions check shapes, prediction agreement, orthogonality or gradients as appropriate. A laptop without a GPU is enough; these experiments do not train a large network.

Starter versions are explicitly incomplete entry points; solution versions are executable. A real-cohort multi-omics project remains planned in school K. No controlled-access clinical dataset is described as freely downloadable.
