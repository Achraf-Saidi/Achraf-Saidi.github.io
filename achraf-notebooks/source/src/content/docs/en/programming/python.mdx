## Why write a program?

You measure three values: 2, 4 and 6. Their mean is $(2+4+6)/3=4$. This is easy by hand; code becomes useful when you repeat calculations, inspect steps and share the exact method. We will build a readable procedure whose expected result is known before execution.

Prerequisite: [fractions](/achraf-notebooks/en/foundations/numbers/). No programming background required. By the end, you will manipulate numerical lists, define functions and test their behaviour.

## Naming a value

In Python, `x = 2` binds the name `x` to an integer object. The statement `x = x + 1` rebinds it to 3; it is not the mathematical assertion $x=x+1$. Equality is tested with `==`. Integers have type `int`, approximate decimal numbers type `float`, and text type `str`.

The statement `values = [2, 4, 6]` creates an ordered list. `values[0]` is 2 because indexing starts at zero. `len(values)` gives length 3. An absent index raises an error rather than inventing a value. Lists may mix types, but a mean function needs inputs compatible with arithmetic.

## Repeating an operation

```python
values = [2, 4, 6]
total = 0
for value in values:
    total = total + value
average = total / len(values)
print(average)  # 4.0
```

The `for` loop takes each list element in turn. Indentation marks its repeated block. The running total becomes 2, then 6, then 12. Division occurs **after** the loop. The function `print` displays a value; it does not return that value for a later calculation.

## Defining a reusable rule

The keyword `def` defines a function; `return` supplies its output. Check for an empty list before dividing by its length:

<CodeLab language="python" lang="en" filename="python-basics.py" code={'def mean(values):\n    if len(values) == 0:\n        raise ValueError("empty list")\n    total = 0\n    for value in values:\n        total += value\n    return total / len(values)\n\nprint(mean([2, 4, 6]))\nassert mean([2, 4, 6]) == 4\n'} />

The `if` block runs when its condition is true. `raise ValueError(...)` signals an invalid input. The shorthand `+=` means add and reassign. Modify the values and run the code; try an empty list to see the error. Runtime state persists between executions until you reset it.

## Libraries after mechanisms

The standard library provides `statistics.mean([2,4,6])`. NumPy suits large homogeneous arrays: `np.mean(array)` expresses a calculation over an array. Libraries do not eliminate semantic checks: missing values, a text column or the wrong axis can change a result’s meaning.

In a real project, save code in a `.py` file, document the Python version and dependencies, and separate raw data from outputs. Notebooks explain experiments well; tested reusable functions help avoid inconsistencies caused by cells executed out of order.

## A precision issue

The expression `0.1 + 0.2 == 0.3` is false under Python’s usual floating-point arithmetic because binary representations approximate these decimals. Use `math.isclose` to compare approximate results, selecting tolerances appropriate to your problem. A tolerance does not excuse errors: it should reflect scale and expected numerical precision.
