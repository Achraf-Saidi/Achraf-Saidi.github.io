---
title: Bilingual glossary
---
A shared vocabulary. Advanced definitions are orientation points; their precise assumptions belong in the corresponding courses.

| Français | English | Definition |
|---|---|---|
| Domaine | Domain | Set of permitted inputs of a function. |
| Image | Image | Set of outputs actually attained. |
| Limite | Limit | Output behaviour as inputs approach a value. |
| Continuité | Continuity | At a point, the limit agrees with the function’s value. |
| Dérivée | Derivative | Limit of the difference quotient when it exists as a finite real number. |
| Gradient | Gradient | Vector of partial derivatives of a scalar function. |
| Vecteur | Vector | Element of a vector space; here, an ordered list of real coordinates. |
| Produit scalaire | Dot product | Sum of products of corresponding coordinates. |
| Matrice | Matrix | Array of numbers whose dimensions determine valid operations. |
| Rang | Rank | Dimension of the space spanned by a matrix’s columns. |
| Probabilité conditionnelle | Conditional probability | P(A given B)=P(A∩B)/P(B), when P(B)>0. |
| Indépendance | Independence | For two events, the intersection probability equals the product of their probabilities. |
| Prévalence | Prevalence | Proportion of people with a condition in a defined population. |
| Vraisemblance | Likelihood | Probability model of observed data viewed as a function of parameters. |
| Loi a priori | Prior distribution | Distribution over parameters before conditioning on the observations being analysed. |
| Loi a posteriori | Posterior distribution | Parameter distribution conditional on the data and model. |
| Perte | Loss | Numerical function expressing an error or cost to minimize. |
| Résidu | Residual | Signed discrepancy between prediction and observation under the stated convention. |
| MSE | MSE | Mean of squared errors. |
| Généralisation | Generalization | Model behaviour on new observations relevant to the intended use. |
| Fuite de données | Data leakage | Information unavailable at the intended prediction time that influences training or evaluation. |
| Rétropropagation | Backpropagation | Efficient gradient computation by applying the chain rule backwards. |
| Censure | Censoring | Partial observation of an event time, such as knowing it exceeds a duration. |
| Calibration | Calibration | Agreement between predicted probabilities and observed frequencies or risks under a specified definition. |
| Décalage de distribution | Distribution shift | Difference between reference and deployment distributions; different forms must be distinguished. |
| Omique | Omics | Collection of measurements of a class of biological components. |
| Effet de lot | Batch effect | Technical variation associated with batch or protocol that can be confounded with biological signal. |
| Modalité | Modality | Type of measurement or representation, such as RNA or proteins. |
| Facteur latent | Latent factor | Unobserved variable summarizing an assumed structure in observations. |
| État, action, récompense | State, action, reward | In RL, an environment description, available decision and signal defining the control problem. |
