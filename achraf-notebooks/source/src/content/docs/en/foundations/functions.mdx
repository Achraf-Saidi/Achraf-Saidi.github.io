## Can a formula be a model?

A taxi charges €4 initially and €2 per kilometre. For distance $x$ in kilometres, its price is $f(x)=4+2x$ euros. The letter $f$ names the rule; $f(x)$ is the output associated with input $x$. At 3 km, $f(3)=10$. This model assumes constant pricing, with no waiting or supplements. A formula applies within its assumptions.

Prerequisite: [variables and equations](/achraf-notebooks/en/foundations/algebra/). Goals: interpret functions, determine domains, construct graphs, compose rules and recognize affine functions.

## A precise definition

A function $f:D\to C$ assigns **each** element $x$ of an input set $D$ **exactly one** value $f(x)$ in an output set $C$. The set $D$ is the **domain**; $C$ is the **codomain**. The set of outputs actually attained is the **image** $f(D)$, which can be smaller than $C$.

For $f:\mathbb R\to\mathbb R$ with $f(x)=x^2$, the domain is $\mathbb R$ but the image is $[0,\infty)$. Inputs 2 and $-2$ share output 4: an output can have several **preimages**. A function cannot assign two different outputs to the same input.

Operations restrict the domain: $g(x)=1/(x-1)$ requires $x\ne1$; the real-valued function $s(x)=\sqrt{x}$ requires $x\ge0$. Context can restrict it further: for the taxi, $x\ge0$.

## Plotting input–output pairs

The graph of $f$ is the set of points $(x,f(x))$. For $f(x)=x^2$, some points are $(-2,4),(-1,1),(0,0),(1,1),(2,4)$. The horizontal axis shows inputs; the vertical axis shows outputs. Joining a few points arbitrarily does not prove what happens between them; the formula and its properties provide that information.

An **affine** function has the form $f(x)=ax+b$, with fixed real numbers $a,b$. Its vertical intercept is $b=f(0)$. For distinct inputs $x_1,x_2$:

$$\frac{f(x_2)-f(x_1)}{x_2-x_1}=\frac{a(x_2-x_1)}{x_2-x_1}=a.$$

This rate of change is constant, and $a$ is its slope. A positive $a$ makes the function increasing; a negative $a$ makes it decreasing; zero makes it constant. An increasing graph need not have constant slope: $x^2$ increases on positive inputs while its slope changes.

## Composing operations

Let $f(x)=x+1$ and $g(u)=u^2$, where $u$ denotes the input of $g$. The composition $g\circ f$ means “apply $f$, then $g$”:

$$(g\circ f)(x)=g(f(x))=(x+1)^2.$$

In the other order, $(f\circ g)(x)=x^2+1$. At $x=2$, the outputs are 9 and 5: order matters. Neural networks are also compositions of transformations.

An **inverse function** reverses a bijective correspondence between the chosen domain and codomain. Squaring on $\mathbb R$ is not invertible because 2 and $-2$ both give 4. Restricting both domain and codomain to $[0,\infty)$ gives square root as its inverse. The notation $f^{-1}$ does not generally mean $1/f$.

## A first implementation

```python
def price(distance):
    if distance < 0:
        raise ValueError("distance must be nonnegative")
    return 4 + 2 * distance

print(price(3))  # 10
```

A Python function implements a procedure; a mathematical function is a correspondence. Here they represent the same rule on accepted numerical inputs. A procedure that changes a file or depends on random draws requires more care in this comparison.

## Exercises

1. For $f(x)=3x-2$, calculate $f(0)$ and find the input producing 10.
2. Give the real domain of $\sqrt{x-2}$.
3. With $f(x)=2x$ and $g(x)=x+3$, calculate $g(f(2))$ and $f(g(2))$.
4. Why does $y^2=x$ fail to define one real output $y$ for every input $x$?

<details>
<summary>Worked solutions</summary>



1. $f(0)=-2$. Solving $3x-2=10$ gives $x=4$.
2. We need $x-2\ge0$, so the domain is $[2,\infty)$.
3. $g(f(2))=g(4)=7$; $f(g(2))=f(5)=10$.
4. For $x=4$, both $y=2$ and $y=-2$ work; for $x<0$, neither is real. Explicitly choosing $y=\sqrt{x}$ on $x\ge0$ fixes both issues.
