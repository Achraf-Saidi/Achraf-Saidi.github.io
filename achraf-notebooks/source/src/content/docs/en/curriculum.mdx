A progression from zero to research, with different entry points. Programming can be studied alongside mathematics; prerequisite links identify essential dependencies.

**Beginner:** start with numbers, then algebra and functions. **Developer:** check derivatives, matrices and probability before regression. **Biomedical researcher:** add biological foundations, statistics and validation before integration methods.
