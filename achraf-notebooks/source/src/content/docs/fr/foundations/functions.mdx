## Une formule peut-elle être un modèle ?

Un taxi facture 4 € de départ puis 2 € par kilomètre. Pour une distance $x$ en kilomètres, son prix est $f(x)=4+2x$ en euros. La lettre $f$ nomme la règle ; $f(x)$ est la sortie associée à l'entrée $x$. Pour 3 km, $f(3)=4+2\times3=10$. Le modèle suppose une tarification constante, sans attente ni supplément : une formule ne vaut que dans son cadre.

Prérequis : [variables et équations](/achraf-notebooks/fr/foundations/algebra/). Objectifs : lire une fonction, déterminer un domaine, construire un graphe, composer des règles et identifier une fonction affine.

## La définition précise

Une fonction $f:D\to C$ associe à **chaque** élément $x$ de l'ensemble de départ $D$ **une unique** valeur $f(x)$ dans l'ensemble d'arrivée $C$. $D$ est le **domaine**. L'ensemble des valeurs réellement atteintes est l'**image** $f(D)$ ; il peut être plus petit que $C$.

Pour $f:\mathbb R\to\mathbb R$, $f(x)=x^2$, le domaine est $\mathbb R$, mais l'image est $[0,+\infty[$. Les entrées 2 et $-2$ partagent la sortie 4 : une sortie peut donc avoir plusieurs **antécédents**. Ce qui est interdit, c'est une même entrée donnant deux sorties dans une même fonction.

Le domaine découle aussi des opérations : $g(x)=1/(x-1)$ exige $x\ne1$ ; $s(x)=\sqrt{x}$, à valeurs réelles, exige $x\ge0$. Le contexte peut le restreindre davantage : pour le taxi, $x\ge0$.

## Dessiner les couples

Le graphe de $f$ est l'ensemble des points $(x,f(x))$. Pour $f(x)=x^2$, quelques points sont $(-2,4),(-1,1),(0,0),(1,1),(2,4)$. L'axe horizontal porte les entrées ; l'axe vertical les sorties. Relier arbitrairement quelques points ne prouve pas ce qui se passe entre eux ; la formule et ses propriétés apportent cette information.

Une fonction **affine** s'écrit $f(x)=ax+b$, où $a,b$ sont des réels fixes. $b=f(0)$ est l'ordonnée à l'origine. Pour deux entrées distinctes $x_1,x_2$ :

$$\frac{f(x_2)-f(x_1)}{x_2-x_1}=\frac{a(x_2-x_1)}{x_2-x_1}=a.$$

Le rapport de variation est constant ; $a$ est la pente. Si $a>0$, la fonction croît ; si $a<0$, elle décroît ; si $a=0$, elle est constante. Un graphe qui monte n'a pas nécessairement une pente constante : $x^2$ croît sur les réels positifs mais sa pente change.

## Composer deux opérations

Prenons $f(x)=x+1$ et $g(u)=u^2$, où $u$ désigne l'entrée de $g$. La composition $g\circ f$ signifie « appliquer $f$, puis $g$ » :

$$(g\circ f)(x)=g(f(x))=(x+1)^2.$$

Dans l'autre ordre, $(f\circ g)(x)=x^2+1$. Pour $x=2$, les sorties sont 9 et 5 : l'ordre compte. Un réseau de neurones sera lui aussi une composition de transformations.

Une fonction **réciproque** inverse une correspondance bijective entre le domaine et l'ensemble d'arrivée choisis. Le carré sur $\mathbb R$ n'est pas inversible, car 2 et $-2$ donnent 4. Restreint à $[0,+\infty[$ et à cet ensemble d'arrivée, il admet la racine carrée comme réciproque. La notation $f^{-1}$ ne désigne pas en général $1/f$.

## Première implémentation

```python
def price(distance):
    if distance < 0:
        raise ValueError("distance must be nonnegative")
    return 4 + 2 * distance

print(price(3))  # 10
```

Une fonction Python réalise une procédure, tandis qu'une fonction mathématique est une correspondance. Ici, elles représentent la même règle sur les entrées numériques acceptées. Une procédure qui modifie un fichier ou dépend d'un tirage aléatoire exige davantage de précautions pour cette comparaison.

## Exercices

1. Pour $f(x)=3x-2$, calculez $f(0)$ et trouvez l'antécédent de 10.
2. Donnez le domaine réel de $\sqrt{x-2}$.
3. Avec $f(x)=2x$ et $g(x)=x+3$, calculez $g(f(2))$ et $f(g(2))$.
4. Pourquoi $y^2=x$ ne définit-il pas une unique sortie réelle $y$ pour toute entrée $x$ ?

<details>
<summary>Corrigé raisonné</summary>



1. $f(0)=-2$. Résoudre $3x-2=10$ donne $x=4$.
2. Il faut $x-2\ge0$, donc $[2,+\infty[$.
3. $g(f(2))=g(4)=7$ ; $f(g(2))=f(5)=10$.
4. Pour $x=4$, $y=2$ et $y=-2$ conviennent ; pour $x<0$, aucune sortie réelle ne convient. Choisir explicitement $y=\sqrt{x}$ sur $x\ge0$ résout ces deux problèmes.
