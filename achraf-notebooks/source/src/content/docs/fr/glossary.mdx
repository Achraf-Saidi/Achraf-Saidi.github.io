---
title: Glossaire bilingue
---
Un vocabulaire partagé. Les définitions avancées sont des points de repère ; les hypothèses précises seront développées dans leurs cours.

| Français | English | Définition |
|---|---|---|
| Domaine | Domain | Ensemble des entrées autorisées d’une fonction. |
| Image | Image | Ensemble des sorties effectivement atteintes. |
| Limite | Limit | Comportement des sorties quand les entrées s’approchent d’une valeur. |
| Continuité | Continuity | Au point considéré, la limite rejoint la valeur de la fonction. |
| Dérivée | Derivative | Limite du quotient de variation, lorsqu’elle existe comme réel. |
| Gradient | Gradient | Vecteur des dérivées partielles d’une fonction scalaire. |
| Vecteur | Vector | Élément d’un espace vectoriel ; ici, une liste ordonnée de coordonnées réelles. |
| Produit scalaire | Dot product | Somme des produits des coordonnées correspondantes. |
| Matrice | Matrix | Tableau de nombres dont les dimensions déterminent les opérations possibles. |
| Rang | Rank | Dimension de l’espace engendré par les colonnes d’une matrice. |
| Probabilité conditionnelle | Conditional probability | P(A sachant B)=P(A∩B)/P(B), lorsque P(B)>0. |
| Indépendance | Independence | Pour deux événements, leur intersection a la probabilité produit. |
| Prévalence | Prevalence | Proportion de personnes présentant un état dans une population définie. |
| Vraisemblance | Likelihood | Modèle probabiliste des observations vu comme fonction des paramètres. |
| Loi a priori | Prior distribution | Distribution des paramètres avant conditionnement sur les observations étudiées. |
| Loi a posteriori | Posterior distribution | Distribution des paramètres conditionnelle aux données et au modèle. |
| Perte | Loss | Fonction numérique exprimant l’erreur ou le coût à minimiser. |
| Résidu | Residual | Écart signé entre prédiction et observation selon la convention annoncée. |
| MSE | MSE | Moyenne des carrés des erreurs. |
| Généralisation | Generalization | Comportement du modèle sur de nouvelles observations pertinentes pour l’usage. |
| Fuite de données | Data leakage | Information non disponible au moment visé qui influence l’apprentissage ou l’évaluation. |
| Rétropropagation | Backpropagation | Calcul efficace des gradients par propagation inverse de la règle de chaîne. |
| Censure | Censoring | Observation partielle du temps d’événement, par exemple savoir qu’il dépasse une durée. |
| Calibration | Calibration | Accord entre probabilités prédites et fréquences ou risques observés, selon une définition précisée. |
| Décalage de distribution | Distribution shift | Différence entre les distributions de référence et d’usage ; ses formes doivent être distinguées. |
| Omique | Omics | Ensemble de mesures d’une classe de composants biologiques. |
| Effet de lot | Batch effect | Variation technique liée au lot ou protocole, susceptible de se confondre avec un signal biologique. |
| Modalité | Modality | Type de mesure ou de représentation, par exemple ARN ou protéines. |
| Facteur latent | Latent factor | Variable non observée résumant une structure supposée des observations. |
| État, action, récompense | State, action, reward | En RL, information décrivant l’environnement, décision possible et signal du problème de contrôle. |
