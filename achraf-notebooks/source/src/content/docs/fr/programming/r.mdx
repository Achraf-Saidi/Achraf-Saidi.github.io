## Une opération, plusieurs observations

En R, `x <- c(2, 4, 6)` crée un vecteur numérique. `<-` affecte une valeur à un nom ; `c` combine des éléments. `x + 1` donne `3 5 7` : l'opération est appliquée à chaque élément. Cette **vectorisation** rend de nombreuses analyses lisibles, à condition de comprendre la taille et le type des objets.

Prérequis : [fractions et proportions](/achraf-notebooks/fr/foundations/numbers/). Objectifs : distinguer vecteur et tableau, sélectionner des lignes, créer une fonction et résumer des groupes. Python n'est pas requis.

## Sélectionner sans se tromper

L'indexation commence à **1** : `x[1]` vaut 2. `x[c(1,3)]` sélectionne les premier et troisième éléments. `x[x > 3]` donne `4 6`, car `x > 3` produit le vecteur logique `FALSE TRUE TRUE`. Un vecteur atomique possède un type commun ; `c(1, "a")` convertit le nombre en texte. Une liste peut contenir des objets de types différents.

Attention au **recyclage** : `c(1,2,3,4) + c(10,20)` donne `11 22 13 24`. R répète le vecteur court. Ce mécanisme peut être voulu, mais il peut aussi masquer un problème de dimensions. Vérifier `length` et `str` aide à le repérer.

## Une fonction et un cas limite

```r
mean_checked <- function(x) {
  if (!is.numeric(x)) stop("numeric vector required")
  if (length(x) == 0L) stop("empty vector")
  if (anyNA(x)) stop("missing values must be handled explicitly")
  sum(x) / length(x)
}
mean_checked(c(2, 4, 6))  # 4
```

`function(x)` définit une fonction. `if` attend une condition logique de longueur 1 ; `!` inverse un booléen. `stop` interrompt avec un message. En R, la dernière expression évaluée est renvoyée, même sans `return`. `NA` signifie une valeur manquante : `mean(c(2,NA,6))` donne `NA`. Avec `na.rm=TRUE`, on calcule sur les valeurs observées ; ce choix change le groupe analysé et doit être justifié.

## Des colonnes reliées par des lignes

Un `data.frame` représente des observations en lignes et des variables en colonnes. Chaque colonne peut avoir son propre type. `$` accède à une colonne. Le laboratoire ci-dessous construit deux groupes et vérifie leurs moyennes :

<CodeLab language="r" lang="fr" filename="r-basics.R" code={'scores <- data.frame(\n  group = c("A", "A", "B", "B"),\n  score = c(10, 14, 8, 12)\n)\nprint(scores)\nprint(tapply(scores$score, scores$group, mean))\nstopifnot(mean(scores$score) == 11)\n'} />

`tapply` sépare le vecteur `score` selon `group`, applique `mean` à chaque morceau et renvoie une synthèse : A vaut 12, B vaut 10. La moyenne globale vaut 11. Avec des groupes de tailles différentes, la moyenne des moyennes n'est pas nécessairement la moyenne globale.

## Une lecture avec dplyr

Dans un environnement local disposant de dplyr récent :

```r
library(dplyr)
scores |> summarise(mean_score = mean(score), .by = group)
scores |> group_by(group) |> summarise(mean_score = mean(score))
```

Le pipe `|>` transmet la sortie de gauche à l'opération de droite. `.by` définit les groupes pour **cette opération**. `group_by` crée un objet groupé qui influence les opérations suivantes ; `ungroup` enlève ce regroupement. Dans ce petit exemple, les résultats numériques coïncident. Un tibble est une variante de tableau avec des choix d'affichage et de sous-sélection plus stricts ; ce n'est pas une nouvelle théorie statistique. Le laboratoire utilise R de base pour éviter tout paquet obligatoire.

## Exercices

1. Que donne `x[x <= 4]` pour `x <- c(2,4,6)` ?
2. Écrivez la moyenne globale après suppression explicite des valeurs manquantes.
3. Les groupes A et B ont respectivement 2 et 8 personnes, et des moyennes 12 et 10. Quelle est la moyenne globale ?
4. Pourquoi `apply` sur un tableau mélangeant texte et nombres peut-il surprendre ?

<summary>Corrigé</summary>



1. Le vecteur `2 4`, après sélection par le masque logique `TRUE TRUE FALSE`.
2. `mean(x, na.rm = TRUE)` ; il faut aussi compter les valeurs observées et expliquer l'exclusion. Si elles sont toutes manquantes, la moyenne observée n'est pas définie.
3. $(2\times12+8\times10)/10=10{,}4$. La moyenne non pondérée des moyennes, 11, serait incorrecte ici.
4. `apply` convertit un data frame en matrice. Un type commun est imposé ; une colonne de texte peut convertir les nombres en caractères. Sélectionnez les colonnes numériques ou utilisez une opération par colonne préservant les types.
