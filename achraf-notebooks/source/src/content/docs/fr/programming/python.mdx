## Pourquoi écrire un programme ?

Vous mesurez trois valeurs : 2, 4 et 6. Leur moyenne vaut $(2+4+6)/3=4$. Ce calcul est facile à la main ; un programme devient utile quand il faut le répéter, vérifier les étapes et partager exactement la méthode. Notre objectif est une petite procédure lisible, dont nous connaissons le résultat avant de l'exécuter.

Prérequis : [fractions](/achraf-notebooks/fr/foundations/numbers/). Aucune programmation préalable. À la fin, vous pourrez manipuler une liste de nombres, écrire une fonction et tester son comportement.

## Nommer une valeur

En Python, `x = 2` associe le nom `x` à un objet entier. `x = x + 1` réaffecte ce nom au résultat 3 ; ce n'est pas une équation mathématique qui affirme $x=x+1$. L'égalité se teste avec `==`. Les nombres entiers ont le type `int`, les approximations décimales le type `float`, et les textes le type `str`.

`values = [2, 4, 6]` crée une liste ordonnée. `values[0]` vaut 2 : les indices commencent à zéro. `len(values)` donne sa longueur, 3. Un indice absent déclenche une erreur plutôt que d'inventer une valeur. Les listes peuvent contenir plusieurs types, mais une fonction de moyenne doit imposer des entrées compatibles avec son calcul.

## Répéter une opération

```python
values = [2, 4, 6]
total = 0
for value in values:
    total = total + value
average = total / len(values)
print(average)  # 4.0
```

`for` prend successivement chaque élément de la liste. L'indentation indique le bloc répété. Après les trois itérations, `total` vaut successivement 2, 6 puis 12. La division est placée **après** la boucle. `print` affiche une valeur ; il ne la renvoie pas comme résultat d'une fonction destinée à d'autres calculs.

## Définir une règle réutilisable

Le mot `def` définit une fonction ; `return` fournit sa sortie. Vérifions la liste vide avant de diviser par sa longueur :

<CodeLab language="python" lang="fr" filename="python-basics.py" code={'def mean(values):\n    if len(values) == 0:\n        raise ValueError("empty list")\n    total = 0\n    for value in values:\n        total += value\n    return total / len(values)\n\nprint(mean([2, 4, 6]))\nassert mean([2, 4, 6]) == 4\n'} />

`if` exécute son bloc si la condition est vraie. `raise ValueError(...)` signale une entrée invalide. L'écriture `+=` signifie « ajouter puis réaffecter ». Modifiez les trois valeurs puis exécutez. Essayez aussi une liste vide pour observer le message. L'état du moteur persiste entre exécutions jusqu'à sa réinitialisation.

## Une bibliothèque, après le mécanisme

La bibliothèque standard offre `statistics.mean([2,4,6])`. Pour de grands tableaux homogènes, NumPy est adapté : `np.mean(array)` exprime un calcul sur un tableau. NumPy ne remplace pas les vérifications : une valeur manquante, une colonne de texte ou un axe mal choisi peut changer le sens du résultat.

Dans un vrai projet, conservez le code dans un fichier `.py`, documentez la version de Python et les dépendances, et séparez les données brutes des résultats. Le notebook est excellent pour expliquer une expérience ; une fonction testée et réutilisable aide à éviter les divergences entre cellules exécutées dans le désordre.

## Une erreur de précision

`0.1 + 0.2 == 0.3` est faux dans l'arithmétique flottante usuelle de Python. La représentation binaire approche ces décimaux. Pour comparer des résultats approchés, utilisez `math.isclose`, avec des tolérances adaptées au problème. Une tolérance n'est pas une permission d'ignorer les erreurs : choisissez-la selon l'échelle et la précision attendue.
