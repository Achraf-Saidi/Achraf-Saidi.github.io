Bellman: derive value iteration and Q-learning

From Markov processes to optimal decisions, a contraction argument, two manual iterations and a programmable MDP.

Method

Define the variables. Re-derive each equation. Reproduce the example independently. Test the code. Explain assumptions and limitations.

Optimal action

Act now for 1 or wait for 2γ.

01 — Defining sequential decisions

An agent acts at discrete steps. A Markov decision process is a tuple (𝒮,𝒜,P,r,γ). 𝒮 is the state space, 𝒜 the action set, P(s′|s,a) the next-state distribution, r(s,a,s′) immediate reward and γ∈[0,1) the discount factor. Assume finite state and action spaces, an infinite horizon and bounded rewards. The Markov property says that, given current state and action, the law of the next state does not depend on the entire history.

A policy π(a|s) specifies action probabilities. Its value is Vπ(s)=Eπ[Σₜ₌₀∞γᵗrₜ | S₀=s]. The expectation incorporates both action sampling and environment transitions. Discounting expresses how future rewards are weighted and helps guarantee convergence for bounded rewards.

02 — Deriving Bellman's equation

Split the return into current reward and continuation: G₀=r₀+γ(r₁+γr₂+⋯)=r₀+γG₁. Linearity of expectation and the Markov property yield Vπ(s)=Σₐπ(a|s)Σₛ′P(s′|s,a)[r(s,a,s′)+γVπ(s′)]. This is Bellman's policy-evaluation equation; no policy optimization has been performed.

For the optimal policy, select the action giving the best expected return: V*(s)=maxₐΣₛ′P(s′|s,a)[r(s,a,s′)+γV*(s′)]. Define the Bellman optimality operator (TV)(s)=maxₐΣₛ′P(s′|s,a)[r+γV(s′)]. Value iteration repeatedly applies this operator to improve value estimates.

03 — Why value iteration converges

For value functions V,W, define ||V−W||∞=maxₛ|V(s)−W(s)|. Averaging with transition probabilities is non-expansive in this norm, and |maxₐfₐ−maxₐgₐ|≤maxₐ|fₐ−gₐ|. Therefore ||TV−TW||∞≤γ||V−W||∞. Because γ<1, T is a contraction. The Banach fixed-point theorem gives a unique optimal value function, and Vₖ₊₁=TVₖ converges to it. Convergence may be slow when γ approaches 1.

04 — Two iterations by hand

Use states A, B and terminal ⊥. At A, an agent may exit for reward 1 or wait, reach B and receive 0. At B, it exits with reward 2. The terminal value is zero. Take γ=0.9 and V₀(A)=V₀(B)=0.

First iteration: V₁(B)=2 and V₁(A)=max(1,0+0.9·0)=1. Second: V₂(B)=2 and V₂(A)=max(1,0+0.9·2)=1.8. This is already a fixed point. Waiting is optimal at A. Future rewards have propagated backward into earlier-state values.

05 — What if dynamics are unknown?

Value iteration assumes a known transition model P and rewards. In model-free reinforcement learning, an agent may estimate action values Q(s,a) from transitions (s,a,r,s′). Q-learning updates Qₙ₊₁(s,a)=Qₙ(s,a)+α[r+γmaxₐ′Qₙ(s′,a′)−Qₙ(s,a)]. The bracketed term is the temporal-difference error. If Q(A,wait)=0, Q(B,exit)=2, r=0, γ=0.9 and α=0.5, the new Q(A,wait) becomes 0+0.5(1.8−0)=0.9.

Tabular convergence requires adequate exploration and step-size assumptions. Replacing a table with a neural network changes the stability problem substantially: function approximation, bootstrapping and off-policy updates may interact poorly.

06 — Reproducible code

This program runs with Python and NumPy on an ordinary computer. It is an educational laboratory, not a clinical or production system.

# A deterministic three-state MDP. Terminal state value is fixed at zero.
gamma = 0.9
value = {"A": 0., "B": 0., "terminal": 0.}
for iteration in range(4):
    new = value.copy()
    new["B"] = 2.0                       # leave B, reward 2
    new["A"] = max(1.0, gamma*value["B"]) # exit now or wait
    value = new
    print(iteration + 1, value)
assert abs(value["A"] - 1.8) < 1e-12
# One Q-learning transition (A, wait, 0, B):
q_a_wait = 0.0
q_b_exit = 2.0
alpha = 0.5
q_a_wait += alpha*(0 + gamma*q_b_exit - q_a_wait)
assert q_a_wait == 0.9

07 — Solved exercise

For this MDP, if γ=0.4, which action is optimal at A? At exactly what discount factor do the actions tie?

Reveal the reasoning and solution

Waiting is worth 2γ=0.8 at γ=0.4; exit earns 1 and is better. The actions tie at 2γ=1, i.e. γ=0.5.
