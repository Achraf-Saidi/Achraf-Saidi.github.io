Backpropagation: full derivation and verification

Differentiate a scalar network, generalize to matrices and understand what autodiff does and does not solve.

Method

Read deliberately: define every symbol, reproduce the example without looking, execute the code, solve the exercises, then watch supplementary lectures. Derivations come first.

Investigate saturation

With x=y=1, w₂=2 and zero biases: inspect tanh and its gradient.

01 — Computation and learning

A network is a composition of parameterized functions. The forward pass computes its output; backpropagation computes derivatives of a loss with respect to parameters; the optimizer uses those derivatives to update parameters. These are three distinct operations.

Consider one observation x=1 with target y=1. Our one-hidden-unit network is z=w₁x+b₁, h=tanh(z), ŷ=w₂h+b₂, with L=(ŷ−y)²/2. All variables are scalars here. The nonlinear activation makes the composition more expressive than one affine transformation.

02 — A numerical forward pass

Let w₁=0.5, b₁=0, w₂=2, b₂=0. Then z=0.5, h=tanh(0.5)=0.462117..., ŷ=0.924234... and L≈0.00287022. Intermediate graph values are cached for differentiation. The activation derivative is tanh′(z)=1−tanh²(z)=1−h².

03 — Chain rule without skipped steps

Start at the loss: δout=∂L/∂ŷ=ŷ−y. For the second layer, ∂L/∂w₂=δout·h and ∂L/∂b₂=δout. Backpropagating to the hidden unit, ∂L/∂h=δout·w₂; since ∂h/∂z=1−h², δhidden=∂L/∂z=δout·w₂·(1−h²). Thus ∂L/∂w₁=δhidden·x and ∂L/∂b₁=δhidden.

Numerically, δout≈−0.075766, ∂L/∂w₂≈−0.03501 and ∂L/∂w₁≈−0.11917. Negative signs show that a small positive change reduces the loss locally, not that an arbitrarily large change is safe.

04 — Matrix calculus and dimensions

For an affine layer z=Wx+b, let x∈ℝᵈ, W∈ℝᵐˣᵈ, b,z∈ℝᵐ, and g=∂L/∂z∈ℝᵐ. Differentiating gives dL=gᵀ(dW x+W dx+db). Matching coefficients yields ∂L/∂W=gxᵀ (shape m×d), ∂L/∂x=Wᵀg (length d), and ∂L/∂b=g. This is the scalar derivation generalized.

Reverse-mode differentiation is efficient for a scalar loss with many parameters. Autodiff libraries build and traverse the graph; they do not establish that the loss is appropriate or that the fitted model generalizes.

05 — Implement and verify

The following code uses NumPy to make each operation explicit and testable. Run it in a local notebook or standard Python environment. Neither a GPU nor personal data is required.

import numpy as np
x, y = 1., 1.
w1, w2, b1, b2 = .5, 2., 0., 0.
def f(a, b):
    return .5 * (b * np.tanh(a*x) - y)**2
z = w1*x+b1
h = np.tanh(z)
y_hat = w2*h+b2
delta_out = y_hat-y
g2 = delta_out*h
g1 = delta_out*w2*(1-h*h)*x
eps = 1e-6
numerical_g1 = (f(w1+eps,w2)-f(w1-eps,w2))/(2*eps)
assert np.isclose(g1,numerical_g1,rtol=1e-6,atol=1e-9)
print(dict(loss=f(w1,w2), grad_w1=g1, grad_w2=g2))

06 — Exercise and solution

When x=0, what is the gradient with respect to w₁? Can the bias gradient be nonzero? Why must all gradients be computed before updating parameters?

Show worked solution

∂L/∂w₁=δhidden·x=0; ∂L/∂b₁=δhidden can be nonzero. An intermediate parameter update would make later gradients refer to a different parameter point.
