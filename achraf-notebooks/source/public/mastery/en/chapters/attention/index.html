Transformers: derive attention and tensor shapes

Q, K, V, softmax, causal masking, multi-head attention, complexity and a NumPy implementation.

Method

Read deliberately: define every symbol, reproduce the example without looking, execute the code, solve the exercises, then watch supplementary lectures. Derivations come first.

01 — Why attention exists

A sequence model needs context. In self-attention, each position forms a weighted combination of representations from permitted positions. Weights depend on the input via learned projections. “Attention” is not human understanding: it is a differentiable vector operation.

Let X∈ℝⁿˣᵈ contain n token embeddings of width d. Learn WQ∈ℝᵈˣᵈᵏ, WK∈ℝᵈˣᵈᵏ and WV∈ℝᵈˣᵈᵛ. Then Q=XWQ, K=XWK, V=XWV. A query indicates what a position seeks, a key supplies a matching signal, and a value contributes to the weighted result. This is intuition, not a replacement for the equations.

02 — Derive the expression

The matrix product QKᵀ has shape n×n; entry (i,j) is the dot product between query qᵢ and key kⱼ. Dividing by √dₖ moderates score magnitudes when vector components have comparable scales. Apply softmax row-wise: αᵢⱼ=exp(sᵢⱼ)/Σₗexp(sᵢₗ). Weights are positive and each row sums to one.

The result is Attention(Q,K,V)=softmax(QKᵀ/√dₖ+M)V. Mask M has zeros for allowed pairs and −∞ for forbidden pairs; causal language modeling blocks future positions. Output shape is n×dᵥ. Positional information must also be supplied: without positional mechanisms, self-attention is permutation equivariant.

03 — Two tokens, a numerical calculation

Take query q=(1,0), keys k₁=(1,0), k₂=(0,1), and dₖ=2. Scores are (1/√2,0)≈(0.7071,0). Softmax gives about (0.6698,0.3302). With values v₁=(2,0) and v₂=(0,4), output is 0.6698v₁+0.3302v₂≈(1.3396,1.3208). Attention mixes representations instead of necessarily picking one token. Weights sum to one; output vector entries need not.

04 — Multi-head attention, cost and pitfalls

With h heads, each has its own projections and builds a distinct weighted mixture. Head outputs are concatenated and projected using WO. Transformer layers typically add a position-wise feed-forward network, residual paths and normalization. A standard attention-weight matrix needs O(n²) memory; score computation and aggregation often cost O(n²d), plus projections. Efficient implementations can improve practical memory without always changing the high-level asymptotic cost.

Subtract row maxima before exponentiating to avoid overflow. Test mask direction and softmax axis. A fully masked row needs special handling; subtracting a maximum of negative infinity leads to NaNs.

05 — Implement and verify

The following code uses NumPy to make each operation explicit and testable. Run it in a local notebook or standard Python environment. Neither a GPU nor personal data is required.

import numpy as np
Q = np.array([[1., 0.]])
K = np.array([[1., 0.], [0., 1.]])
V = np.array([[2., 0.], [0., 4.]])
scores = Q @ K.T / np.sqrt(K.shape[1])    # shape (1,2)
scores -= scores.max(axis=-1, keepdims=True)
weights = np.exp(scores)
weights /= weights.sum(axis=-1, keepdims=True)
output = weights @ V                       # shape (1,2)
assert np.allclose(weights.sum(axis=-1), 1)
print("weights:", weights)
print("output:", output)

06 — Exercise and solution

If Q is 8×16, K is 8×16 and V is 8×32, what are the shapes of QKᵀ, attention weights and output? Why must the future be masked during autoregressive generation?

Show worked solution

QKᵀ is 8×8; softmax weights are 8×8; output is 8×32. Without a causal mask, training would permit information from future tokens not available at autoregressive inference.
