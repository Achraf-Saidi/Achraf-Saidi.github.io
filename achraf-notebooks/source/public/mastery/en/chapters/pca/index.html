PCA: from geometry to eigenvectors

Why is the best direction an eigenvector? A Lagrange derivation, projection, SVD, hand calculations and NumPy.

Method

Read deliberately: define every symbol, reproduce the example without looking, execute the code, solve the exercises, then watch supplementary lectures. Derivations come first.

PCA — variance versus angle

Variance is 2 + sin(2θ), maximized at 45°.

01 — The geometric question

A data table contains n observations and d features. Each row is a point in d-dimensional space. Principal component analysis (PCA) seeks orthogonal directions along which the projected observations vary most. These directions combine original features: PCA does not select an existing subset of columns.

Let X ∈ ℝⁿˣᵈ contain centered columns, so Σᵢ Xᵢⱼ = 0. The empirical covariance is S = XᵀX/(n−1), a symmetric positive-semidefinite d×d matrix. For a unit vector w ∈ ℝᵈ, projection gives z = Xw ∈ ℝⁿ.

02 — Deriving the optimization

The sample variance of projected coordinates is Var(z)=zᵀz/(n−1)=wᵀSw. Therefore solve max₍w₎ wᵀSw subject to wᵀw=1. Without the unit-length constraint, increasing the scale of w would increase the objective without bound.

Introduce ℒ(w,λ)=wᵀSw−λ(wᵀw−1). Symmetry gives ∇w(wᵀSw)=2Sw and ∇w(wᵀw)=2w. Setting the derivative to zero yields Sw=λw, the eigenvector equation. Left multiply by wᵀ: wᵀSw=λwᵀw=λ. Hence each eigenvalue equals the sample variance along its unit eigenvector; the largest eigenvalue gives the maximum. For subsequent axes, impose orthogonality to the previous ones. The spectral theorem supplies orthonormal eigenvectors of symmetric S. The first k jointly maximize tr(WᵀSW) under WᵀW=Iₖ.

03 — A complete hand calculation

Consider S=[[2,1],[1,2]]. Its characteristic equation is det(S−λI)=(2−λ)²−1=(λ−3)(λ−1)=0. Thus λ₁=3 and λ₂=1. Solving (S−3I)w=0 gives w₁=(1,1)/√2; the other direction is w₂=(1,−1)/√2. The first principal component explains 3/(3+1)=75% of total variance. The sign of an eigenvector is arbitrary: −w₁ is the same axis.

Retaining only that component yields scores z=Xw₁ and centered reconstruction X̂=zw₁ᵀ. For k axes, Z=XW and X̂=ZWᵀ. Add back means and undo scaling when reconstructing original units.

04 — Why SVD is usually preferred

Use the singular value decomposition X=UΣVᵀ, with orthonormal singular vectors and σⱼ≥0. It follows that S=VΣ²Vᵀ/(n−1). Principal axes are columns of V, and component variances equal σⱼ²/(n−1). Explicitly building XᵀX can worsen numerical conditioning, so computing SVD on X is often preferable. PCA depends on feature scale and can be distorted by outliers; standardization is a modeling decision rather than an automatic rule.

05 — Implement and verify

The following code uses NumPy to make each operation explicit and testable. Run it in a local notebook or standard Python environment. Neither a GPU nor personal data is required.

import numpy as np
X = np.array([[2., 1.], [3., 2.], [4., 5.], [5., 4.]])
mean = X.mean(axis=0)
Xc = X - mean
U, singular, Vt = np.linalg.svd(Xc, full_matrices=False)
scores = Xc @ Vt.T
variances = singular**2 / (len(X) - 1)
reconstructed = scores[:, :1] @ Vt[:1, :] + mean
assert np.allclose(np.cov(Xc, rowvar=False) @ Vt[0], variances[0] * Vt[0])
print("Explained variance:", variances / variances.sum())
print("Rank-1 reconstruction:", reconstructed)

06 — Exercise and solution

For covariance [[2,1],[1,2]], compute projected variance along w=(1,−1)/√2. Why is (1,1) better? What is the rank of the one-component centered reconstruction?

Show worked solution

wᵀSw=1; the orthogonal axis has eigenvalue 3, so it retains three times the variance. The centered reconstruction has rank at most 1.
