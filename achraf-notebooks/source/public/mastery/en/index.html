05 / Turn learning into expertise

Mastery protocol

At the end of every module

Explain a definition unaided, reconstruct a full derivation, do a numerical exercise, implement a test and describe one failure case. Watching a lecture is not mastery.

Each month

Ship a project report with data, assumptions, simple baseline, metrics, ablations, uncertainty, failure cases and reproducibility.

At research level

Reproduce a paper on public data, identify a debatable assumption, design a discriminating experiment and report both negative results and limitations.
