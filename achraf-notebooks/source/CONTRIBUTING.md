# Contributing to Achraf Notebooks

Start with a focused issue: identify the lesson, passage, reproducible error and proposed
correction. For new lessons choose a stable curriculum concept ID and discuss its scope.

Read docs/AUTHORING.md before writing. Supply French and English versions with equivalent
mathematics, checked examples, exercises, explained solutions and primary references.
Record technical validation separately from independent scientific review. Do not copy
third-party text, figures or datasets without an appropriate licence and attribution.

Run npm ci, npm run verify and, when changing project code, the Python reference scripts.
Keep PRs focused. No generated chapter lists should be presented as completed teaching.

Contributions are under MIT for code and CC BY 4.0 for original teaching prose.
