# Achraf Saidi — Academic website

The personal academic and professional website of **Achraf Saidi**, PhD researcher and Teaching & Research Assistant at **UCLouvain (ISBA / LIDAM)**, and **co-founder & CTO of NovalisAI**.

Live site: https://achraf-saidi.github.io/

## Content

- Research interests and research software
- Selected applied experience
- Teaching
- Biography
- Contact (academic and company enquiries kept separate)
- Technical notes and a separate archive of software projects

## Design & deployment

Lightweight, responsive HTML/CSS/JavaScript. The main website is intentionally styled as an academic profile, not a product landing page. No analytics, cookies or build process are required for the profile pages. Published directly from the `main` branch via GitHub Pages.

## Maintenance

Update public biographical details in `index.html`, `about/index.html` and `projects/index.html`. Add publications, ORCID or a CV only when verified public links or documents are available.
